# 🚀 Vaibhav Kundu — 3D Cyber-Space Portfolio Website

An interactive, 3D game-like portfolio website built with **Three.js**, **React 19**, and **Vite**, showcasing research, machine learning projects, accolades, and experience.

## 🎮 Key Features & Gameplay

- **🕹️ Free Roam Game Mode**: Pilot a futuristic cyber hovercraft across an expansive neon grid terrain using keyboard controls (`W`, `A`, `S`, `D` / Arrow keys) or on-screen touch joystick on mobile.
- **🚀 Director Tour Mode**: Smooth cinematic autopilot camera flights between stations for instant navigation.
- **⚡ Collectible Data Cubes**: 12 glowing data orbs scattered across the terrain that grant XP score when collected.
- **🔊 Procedural Audio Synthesizer**: Native Web Audio API engine providing hovercraft thruster audio, proximity alerts, data pickup chimes, and UI sounds (with a one-click Mute switch).
- **🤖 NOVA — AI Co-Pilot**: Real-time holographic assistant powered by Google Gemini API, grounded in Vaibhav's research and projects.
- **✨ 6 Interactive Thematic Stations**:
  1. **Command Deck**: Holographic identity hub with profile portrait, bio, tactical background, and resume download.
  2. **Neural Nexus**: 3D interactive glowing neural network visualizing machine learning, frameworks, and programming skills.
  3. **Defense Hangar**: Tactical radar array and live speech processing audio frequency visualizer spotlighting DRDO CABS research (NVIDIA NeMo, Titanet-L, MarbleNet, MSDD) + industry internships (Sasken, Celebal, IEEE CIS, Infosys).
  4. **Trophy Vault**: 3D golden award pedestal celebrating the **IEEE SPACE 2026 Best Paper Award** for *“AI-Based Voice Deception System for Aerospace and Defense”*.
  5. **Cyber Archives**: Holographic monolithic data towers documenting Netaji Subhas Engineering College (B.Tech CSE, Vice President of GNX) and South Point High School honors.
  6. **Quantum Relay**: Deep space comms array with working Formspree integration and an AI-powered Recruiter Auto-Pitch Drafter.

## 🛠️ Tech Stack

- **3D Engine**: Three.js (WebGL, procedural geometries, custom particle systems, lighting)
- **Frontend & UI**: React 19, CSS Modules, Glassmorphism, Orbitron / Rajdhani typography
- **Audio Engine**: HTML5 Web Audio API
- **Build System**: Vite
- **Integrations**: Google Gemini API, Formspree

## 💻 Local Development

1. Clone or navigate to the repository:
   ```bash
   cd My_Portfolio_Website
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
